# Abdul Hadi invites Rainbow to dinner 💗

A cute pastel dinner invitation website made with plain HTML, CSS and JavaScript.

## Files
- `index.html` — invitation content
- `style.css` — responsive pastel styling
- `script.js` — Yes/Later responses and celebration animation

## Preview
Open `index.html` in any modern browser.

## Publish with GitHub Pages
1. Sign in at https://github.com/.
2. Create a new **public** repository named `abdul-hadi-invites-rainbow`.
3. Upload `index.html`, `style.css`, `script.js`, and `README.md` directly into the repository root.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch `main` and folder `/(root)`, then press **Save**.
7. Wait for GitHub Pages to publish. The URL will be:
   `https://YOUR-USERNAME.github.io/abdul-hadi-invites-rainbow/`

The buttons display a response on the page; they do not send a notification. No backend or build process is needed.
